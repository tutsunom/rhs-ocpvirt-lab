= まとめと追加情報

image::2025_spring/conclusion/00_Thank_You.png[link=self, window=blank, width=100%]

本ラボを通じて、Azure Red Hat OpenShift（ARO）上の OpenShift Virtualization が、どのように仮想マシンを Kubernetes ベースのプラットフォームへ統合し、移行からモダン化への明確な道筋を提示できるかをご体験いただきました。
ラボでは、Migration Toolkit for Virtualization（MTV）を用いた VM の作成と移行（高度なオプションやフックを含む）に始まり、PVC、スナップショット、クローンによるストレージの基礎、そして OADP を使用した VM 対応のバックアップとリストアを実施しました。
また、テンプレートや InstanceType を使用した効率的なプロビジョニング、さらに Service と Route を介した VM アプリケーションの公開といった Day-2 運用を実行しました。これらにより、VM ワークロードがコンテナと同様のクラウドネイティブなワークフローに参加できることを実証しました。

この {lab_name} をお楽しみいただけたなら幸いです。*OpenShift Virtualization* についての学びが、レガシーな仮想マシンのインポートや管理に役立つツールとして、またアプリケーション・モダン化への一歩として、皆様の今後の活動に寄与することを願っています。

[[key_takeaways]]
== 本ハンズオンワークショップのまとめ

* OpenShift Virtualization はソリューション指向であり、成熟し、安定しており、かつ拡張性の高いソリューションを、すぐに使い始めることができる形で提供します。

* OpenShift Virtualization は、ハイブリッドクラウド・アプリ開発プラットフォームを提供する「OpenShift Platform Plus」から、仮想化ワークロードのサポートに特化した「OpenShift Virtualization Engine」まで、あらゆるレベルの OpenShift サブスクリプションで利用可能です。

* OpenShift Virtualization は広範なパートナー製品のエコシステムと完全に統合されており、その数は日々増え続けています。お使いのハードウェアおよびソフトウェアベンダーが OpenShift Virtualization をサポートしているか、ぜひご確認ください。

* OpenShift Virtualization は、従来のワークロードに対して強力な基盤を提供すると同時に、モダンなアプリケーション・プラットフォームを通じて将来に向けたスキルを習得する助けとなります。

=== 仮想化移行評価（Virtualization Migration Assessment）

移行に向けた具体的なロードマップを作成するための、Red Hat によるプロフェッショナルサービスです。

* **オンサイト・ワークショップ:** Red Hat の経験豊富なアーキテクトが 2 週間にわたりオンサイトで対話型ワークショップを実施し、移行に向けた戦略立案を支援します。
* **包括的な環境レビュー:** ネットワーク、ストレージ、セキュリティ、バックアップ、ディザスタリカバリ（DR）など、現在の仮想化環境と統合状況を広範囲にレビューします。
* **VMA レポートの提供:** 高レベルの推奨事項、設計上の考慮事項、および完全な移行に向けたカスタマイズ済みの提案書（プロポーザル）を提供します。
* **確実な意思決定:** 移行の目的地、到達プロセス、必要な期間、およびコストを明確に把握し、プロジェクトの確実な遂行を支援します。

詳細については、**https://www.redhat.com/en/resources/virtualization-migration-assessment-datasheet[こちらのリンク^]**をクリックするか、下記の QR コードをスキャンしてください。
