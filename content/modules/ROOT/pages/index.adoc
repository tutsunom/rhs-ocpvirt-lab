= Azure Red Hat OpenShift (ARO) 上の OpenShift Virtualization ワークショップへようこそ！

== はじめに
Azure Red Hat OpenShift（ARO）上で稼働する Red Hat OpenShift Virtualization は、従来の仮想化プラットフォームからモダンなクラウドネイティブ・インフラストラクチャへの移行を目指す組織にとって、明確で実践的な道筋を提供します。
仮想マシン（VM）を Kubernetes ベースの基盤に統合することで、既存のワークロードを確実に維持しながら、長期的なモダン化とイノベーションへの段階を整えることができます。

Red Hat と Microsoft が共同開発した ARO 上の OpenShift Virtualization は、仮想マシン、コンテナ、サーバーレス・ワークロードの管理を単一の統合環境に集約した、セキュアでエンタープライズグレードのプラットフォームを提供します。
Migration Toolkit for Virtualization（MTV）や Ansible Automation Platform（AAP）などのツールを活用することで、管理者は移行を効率化し、日々の運用を自動化して、ハイブリッド/マルチクラウド環境全体の複雑さを軽減できます。

ARO で実行される OpenShift Virtualization は、マネージドサービスとしての利点、自動化された Day 2 運用、継続的なアップデートを提供します。これにより、Red Hat のオープンソース・イノベーションと RHEL の専門知識を、Microsoft Azure の高い信頼性とスケールメリットと組み合わせて利用可能です。
その結果、柔軟で安全かつ将来性の高いプラットフォームが実現し、運用負荷を抑えながら、組織のペースに合わせたモダン化を推進できます。

本ワークショップは、ARO 上の OpenShift Virtualization を実践的に学ぶための入門編です。
VM の作成、移行、自動化、ライフサイクル管理など、実際の現場で使用されるツールやワークフローを用いて、一般的な管理業務と運用タスクを体験します。
ラボの終了までに、OpenShift Virtualization がいかに VM 管理を簡素化し、プラットフォームの効率を高め、ハイブリッドクラウド・モダン化の基盤となるかを理解いただけるはずです。

== 本ハンズオンワークショップの対象読者

* **仮想マシン管理者** -- OpenShift Virtualization における VM の日常的な管理を担当する方。VM のプロビジョニング、メンテナンス、および内部で実行されるアプリケーションの管理に責任を持つユーザーを想定しています。

* **仮想インフラ管理者** -- OpenShift Virtualization をホストする物理インフラ（ハードウェア、ストレージ、ネットワーク）の責任者。インフラの変更が VM 運用に与える影響を理解し、最適化を行うユーザーを想定しています。

== 本ハンズオンワークショップで扱うコンテンツ

本ラボは、以下の **6つ** の主要セクションで構成されています：

* **仮想マシン管理**: VM の作成やリソース割り当ての変更など、管理の基礎を学びます。

* **既存の仮想マシンの移行**: Migration Toolkit for Virtualization（MTV）を使用し、VMware vSphere 環境から OpenShift Virtualization への移行を実施します。

* **ストレージ管理**: OpenShift Virtualization におけるストレージ管理のアクションを確認し、従来のストレージパラダイムがどのように変化するかを探索します。

* **仮想マシンのバックアップとリカバリ**: VM の外部バックアップと、災害時のリストアに関する概念と実演を行います。

* **テンプレートと InstanceType 管理**: デプロイを効率化するためのカスタムテンプレート作成と、InstanceType（インスタンスタイプ）の定義に焦点を当てます。

* **仮想マシンとアプリケーションの操作**: インポートした VM に対して Day 2 運用を行い、Service と Route を経由して VM 上のアプリケーションを外部に公開します。

// * **ネットワーク管理**: OpenShift のポッドネットワークへの接続に加え、L2 ネットワークマッピングの作成や、直接接続のためのユーザー定義ネットワーク（UDN）について学びます。

== OpenShift Virtualization とは？

* OpenShift のサブスクリプションをお持ちであれば、追加費用なしで OpenShift Virtualization を利用可能です。ARO では OpenShift 4.18 より正式にサポートされています。
* 本技術は、CNCF（Cloud Native Computing Foundation）のインキュベーションプロジェクトである **KubeVirt** をベースにした「コンテナネイティブ仮想化」技術です。
* **Red Hat Enterprise Linux KVM (RHEL KVM)** ハイパーバイザーを活用しています。これは 15 年以上の実績があり、世界中のクラウドプロバイダーで採用されている成熟したオープンソース・ハイパーバイザーです。
* VM は Kubernetes のスケジューリング、ネットワーク、ストレージインフラをそのまま利用します。つまり、VM も Kubernetes 上のひとつのオブジェクトとして管理されます。

* Microsoft の Windows ゲストサポート向けに **SVVP 認定** を受けており、Red Hat の他の KVM 製品と同様のサポートルールが適用されます。
* ARO 上では、特定の「Boost」インスタンスタイプでサポートされています。詳細は https://learn.microsoft.com/ja-jp/azure/openshift/howto-create-openshift-virtualization[Microsoft のドキュメント] を参照してください。
* VM を OpenShift クラスタ内のリソースとして統合することで、GitOps、CI/CD パイプライン、Service Mesh などのモダンな機能を仮想マシンに対しても適用できるようになります。

== 従来の VM プラットフォームから移行する理由

* **クラウドネイティブ運用へのシフト:** ARO を利用することで、チームはスピード、俊敏性、選択肢を持ってアプリを構築できます。インフラ管理ではなく、価値を生むコーディングに集中できます。
* **完全なアプリ開発スタック:** Red Hat OpenShift Dev Spaces、ランタイム、サーバーレス、パイプラインなど、セキュリティを備えた包括的なツール群が統合されています。
* **インフラ支出をイノベーションへ:** SDDC（Software-Defined Data Center）などの重厚なレガシー環境から、軽量なコンテナネイティブ・フレームワークに移行することで、コスト構造を最適化できます。
* **ロックインのリスク軽減:** OpenShift はオンプレミスとパブリッククラウドの両方をサポートしているため、特定のクラウドベンダーへのロックインを防ぐ保険となります。
* **インフラからの独立:** ベアメタル、オンプレミス仮想化、クラウドのどこでも一貫して動作するため、デプロイ先を柔軟に選択できます。
* **オープンソースによるイノベーション:** Kubernetes、Serverless、Service Mesh などの最新技術は、Red Hat がリードするオープンソースコミュニティの速度によって進化し続けています。
